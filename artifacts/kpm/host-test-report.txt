behavior. They are not included in the Android/KPM artifacts.

Go's race detector passed all Go integration packages. A separate C
ThreadSanitizer run is not claimed: the available VM runtime terminated with
"unexpected memory mapping", an environment limitation already reproduced
during implementation.
